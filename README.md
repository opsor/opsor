<h2 id="about"><img src="https://api.iconify.design/lucide/user.svg?color=%235fa8c8" width="20" align="absmiddle" />&nbsp; About</h2>

I build reliable software that automates repetitive work: multi-account automation, bot fleets with their control layers, and polished Windows desktop apps. Everything is designed to run unattended, recover from failure on its own, and notify you only when it needs you.

| | |
| :-- | :-- |
| **Focus** | Automation, orchestration, desktop apps |
| **Principles** | Autonomous, secure, tested, simple to operate |
| **Delivery** | Windows installers with auto-update, clear docs, source handover |
