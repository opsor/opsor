<h2 id="what-i-do">
<img src="https://api.iconify.design/lucide/rocket.svg?color=%23818cf8" width="22" align="absmiddle" /> What I Build
</h2>
<img src="https://api.iconify.design/lucide/swords.svg?color=%236366f1" width="18" align="absmiddle" /> Game automation & bots
From headless Minecraft clients to multi-account managers — I build tools that connect, navigate, farm, and react to in-game events automatically while keeping accounts safe.
<img src="https://api.iconify.design/lucide/cpu.svg?color=%236366f1" width="18" align="absmiddle" /> Software that looks after itself
Good software doesn't need babysitting. My projects are built with automatic reconnects, self-healing routines, and smart resource management so they recover from issues on their own.
<img src="https://api.iconify.design/lucide/home.svg?color=%236366f1" width="18" align="absmiddle" /> Clean desktop & web interfaces
Complex logic underneath, simple controls on top. Every tool gets an intuitive interface so managing dozens of accounts or processes takes a single click instead of a terminal window.
<img src="https://api.iconify.design/lucide/siren.svg?color=%236366f1" width="18" align="absmiddle" /> Built to stay out of trouble
Whether it is rate-limiting, stranger detection, or safe-logout triggers, safety and privacy are built right into the core of every project.
