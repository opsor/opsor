The Journey: From Logic to Neural Architecture
My foundation in software engineering was built on deterministic systems—crafting high-performance desktop applications, reverse-engineering network protocols, and building robust web architectures. Early on, I was obsessed with optimizing execution loops and building clean, component-driven interfaces that bridged complex backends with seamless user experiences.
The Pivot to AI & LLMs
As machine learning began transitioning from academic theory to practical application, my focus shifted. I was no longer satisfied with writing static algorithms; I wanted to build systems that could reason, adapt, and operate autonomously.
My deep dive into Large Language Models (LLMs) started out of a desire for complete control. Rather than relying solely on black-box commercial APIs, I began exploring local inference and bare-metal compute. This meant understanding the hardware layer—VRAM allocation, quantization formats (GGUF, AWQ, EXL2), and model benchmarking. Today, my work heavily revolves around multi-agent orchestration, where I design systems that allow specialized, locally hosted models to interact, use tools, and execute complex workflows without human intervention.

Technical Capabilities & Engineering Stack
I build across the entire stack, from microcontroller telemetry up to autonomous AI networks. Here is a breakdown of my primary capabilities:
1. Core Languages
￼ TypeScript / JavaScript: Advanced proficiency. Building complex, typed architectures for React, Next.js, and Node.js environments.
￼ Python: The backbone of my AI workflow. Used for data pipelines, LangChain orchestration, machine learning scripts, and heavy backend logic.
